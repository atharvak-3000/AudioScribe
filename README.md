# AudioScribe

A modern AI-powered video conferencing platform with automatic meeting summarization, speaker identification, and action item extraction.

## Features
- HD Video Meetings
- AI Meeting Summaries powered by Groq
- Speaker Identification via Stream Transcription
- Action Items Extraction
- Summary History
- Meeting Analytics
- PDF Export
- Shareable Summary Links

## Tech Stack
- Next.js 14
- Stream Video SDK
- Clerk Authentication
- AssemblyAI Transcription
- Groq AI (Llama 3)
- Tailwind CSS
- TypeScript

## Setup
1. Clone the repo
2. Run `npm install` 
3. Add environment variables to `.env.local` 
4. Run `npm run dev`
